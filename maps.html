Importer et jouer

Choisir un fichier JSON. Il sera vérifié avant de remplacer la carte importée.

Jouer la carte importée

La carte importée est conservée dans ce navigateur. Le brouillon de l’éditeur est séparé.

Charger automatiquement un fichier

  1. Dans l’éditeur : Exporter la carte.
  2. Déplacer le fichier téléchargé dans le dossier maps du projet, avec le nom active.json.
  3. Ouvrir ou recharger le jeu.

Le fichier maps/active.json est prioritaire au lancement normal. Sans ce fichier, le jeu utilise la carte importée dans ce navigateur, puis la carte originale.
